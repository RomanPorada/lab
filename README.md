## Лабораторні роботи з дисципліни "Алгоритми та структури даних"

## Виконав: Порада Роман Ярославович(ІР-13)
## Лабораторна робота(Варіант 5)

Відновлення кроків гри: гравець може вертатися назад під час гри, щоб дати іншу відповідь на питання
Посадка пасажирів в автобус: кожен пасажир сідає в автобус в порядку того як вони прийшли на зупинку
